# Chat UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a sleek, modern AI Chat interface using Vite + React with official shadcn/ui components (including `SidebarProvider`, `Sidebar`, `SidebarTrigger`), a dynamic Model Selector for per-message model sharing, deferred chat registration, and real-time SSE streaming.

**Architecture:** A unified `ChatContext` coordinates thread state, deferred registration, and SSE streaming against the FastAPI backend via a zero-CORS Vite dev proxy. Official shadcn components provide the layout (collapsible sidebar, dropdown menus, buttons, inputs) while a dedicated Markdown component handles streaming syntax-highlighted code output.

**Tech Stack:** React 19, Vite, Tailwind CSS v4, official shadcn/ui (radix-ui, lucide-react, clsx, tailwind-merge), react-markdown, Vitest + @testing-library/react.

## Global Constraints

- Backend files in `backend/` must remain untouched — DO NOT MODIFY BACKEND.
- `POST /chat` registers chat on first message: clicking "New Chat" must NOT call the backend.
- Every message sent to `POST /chat` must include `{ model: string, message: string, thread: string }`.
- Available models: `gpt-oss-120b` (default), `stealth/space-bunny-alpha`, `nvidia/nemotron-3`.
- Model selector must live in `ChatHeader` and allow switching at any time before sending.
- Official shadcn CLI and components must be used (not mimicked).
- Frequent, atomic Git commits after every task.

### Task 3: Chat Context & SSE Streaming Engine

**Files:**
- Create: `frontend/src/context/ChatContext.jsx`
- Test: `frontend/src/test/ChatContext.test.jsx`

**Interfaces:**
- Consumes: `fetch` API, `/chat`, `/listchats`, `/chat/{thread_id}` endpoints.
- Produces: `useChat()` hook providing:
  - `chats`: Array of `{ thread, title, updated_at }`
  - `activeThread`: String UUID of currently selected or pending thread
  - `messages`: Array of `{ role: 'user' | 'assistant', content: string }`
  - `selectedModel`: String (`gpt-oss-120b` | `stealth/space-bunny-alpha` | `nvidia/nemotron-3`)
  - `setSelectedModel(model)`: Function
  - `isGenerating`: Boolean
  - `startNewChat()`: Function (generates UUID locally, does NOT call backend)
  - `selectChat(threadId)`: Function (loads `/chat/{thread_id}`)
  - `sendMessage(prompt)`: Function (sends `{ model, message, thread }`, handles SSE streaming, triggers `fetchChats`)
  - `stopGeneration()`: Function (aborts active stream via AbortController)
  - `fetchChats()`: Function (fetches `/listchats?limit=50&offset=0`)

- [ ] **Step 1: Write unit tests for ChatContext deferred registration and streaming**

```jsx
// frontend/src/test/ChatContext.test.jsx
import { describe, it, expect, vi, beforeEach } from 'vitest'
import { renderHook, act } from '@testing-library/react'
import { ChatProvider, useChat, AVAILABLE_MODELS } from '../context/ChatContext'

describe('ChatContext', () => {
  beforeEach(() => {
    vi.restoreAllMocks()
  })

  it('initializes with default model gpt-oss-120b and a local thread ID', () => {
    const { result } = renderHook(() => useChat(), { wrapper: ChatProvider })
    expect(result.current.selectedModel).toBe('gpt-oss-120b')
    expect(result.current.activeThread).toBeDefined()
    expect(result.current.messages).toEqual([])
    expect(result.current.isGenerating).toBe(false)
  })

  it('startNewChat does NOT hit backend and generates a new local UUID', () => {
    const fetchSpy = vi.spyOn(global, 'fetch')
    const { result } = renderHook(() => useChat(), { wrapper: ChatProvider })
    const initialThread = result.current.activeThread

    act(() => {
      result.current.startNewChat()
    })

    expect(result.current.activeThread).not.toBe(initialThread)
    expect(result.current.messages).toEqual([])
    // Crucial requirement: No fetch call on new chat creation!
    expect(fetchSpy).not.toHaveBeenCalled()
  })

  it('updates selectedModel correctly', () => {
    const { result } = renderHook(() => useChat(), { wrapper: ChatProvider })
    act(() => {
      result.current.setSelectedModel('stealth/space-bunny-alpha')
    })
    expect(result.current.selectedModel).toBe('stealth/space-bunny-alpha')
  })
})
```

- [ ] **Step 3: Implement `frontend/src/context/ChatContext.jsx`**

Implement `ChatContext` with:
- `AVAILABLE_MODELS = [ { id: 'gpt-oss-120b', label: 'GPT-OSS 120B' }, { id: 'stealth/space-bunny-alpha', label: 'Space Bunny Alpha' }, { id: 'nvidia/nemotron-3', label: 'Nemotron-3' } ]`
- `startNewChat()`: generates `crypto.randomUUID()`, resets messages, marks `isNewThread = true`, no backend request.
- `sendMessage(prompt)`:
  - Appends user message and assistant placeholder.
  - Creates `AbortController`.
  - Dispatches `POST /chat` with body `JSON.stringify({ model: selectedModel, message: prompt, thread: activeThread })`.
  - Reads SSE stream: split buffer by `\n\n`, parse lines starting with `data: `, extract `JSON.parse(line.slice(5)).content`, append to assistant message.
  - On stream end: refetches `GET /listchats?limit=50&offset=0`.
- `selectChat(threadId)`: calls `GET /chat/${threadId}`, maps `{ type: 'human' }` -> user, `{ type: 'ai' }` -> assistant.
- `stopGeneration()`: calls `abortController.abort()`.
